# 🌀 Папка «Переворот» — Геометрический Фреймворк ЕТВП / ЕТВЭ

Этот каталог является главным научно-доказательным узлом репозитория. Его цель — **полная геометризация фундаментальной физики**. 

Вместо эмпирической подгонки констант Стандартной модели под результаты экспериментов, представленные здесь алгоритмы и манифесты последовательно выводят архитектуру Вселенной из первых принципов: 11-мерного пространства-времени, исключительной группы Ли $E_8$ и динамики суперсимметричных $D$-бран.

---

## 📂 Навигация и краткое описание файлов

### 1. Первичный численный синтез
*   **`константа1.md`** — Теоретический манифест, объявляющий о выводе постоянной тонкой структуры ($\alpha^{-1}$) из чистой геометрии.
*   **`Константа1.py`** — Базовый исполняемый скрипт. Демонстрирует, что сила электромагнитного взаимодействия ($\alpha^{-1} \approx 137.036$) собирается без единой физической вводной, на основе трансцендентного базиса числа Пи ($\pi$), Золотого сечения ($\Phi$) и резонанса $\sqrt{3}$.

### 2. Топологический базис
*   **`Константа1топология.py`** — Строгое геометрическое обоснование формулы $\alpha^{-1}$. Каждое слагаемое привязывается к многомерным инвариантам: 4D-проекции решетки $E_8$, топологическому дефекту сворачивания измерений и спинорной калибровке группы $Spin(7)$ с размерностью $2^7 = 128$.

### 3. Сквозная применимость и Первые принципы
*   **`Доказательство единственности геометрического базиса.py`** — Расширение фреймворка на весь каркас физики. Используя те же геометрические модули, алгоритм без подгонки рассчитывает: гравитационную постоянную Ньютона ($G$), идеальное отношение масс протона и электрона ($m_p/m_e \approx 1836.15$), массы тяжелых калибровочных $W/Z$-бозонов и массу электрона.
*   **`ВЫВОД ИЗ ФУНДАМЕНТАЛЬНЫХ ДЕЙСТВИЙ.py`** — Интеграция геометрических модулей в классический аппарат квантовой теории поля и ОТО. Выводит константы напрямую из компактификации полных функционалов — действий Эйнштейна — Гильберта и Янга — Миллса для группы $E_8$.
*   **`Закрывающий споры.md`** — Математическое доказательство стабильности вакуума. Выводит радиус скрытых измерений ($R = \Phi^2$) из уравнений движения $D$-браны Дирака — Борна — Инфельда (DBI) при условии сохранения суперсимметрии $N=1$.

### 4. Верификация и Фальсифицируемость
*   **`предсказание для FCC — расчёт α_s и углов смешивания нейтрино...py`** — Слепые предсказания Новой Физики. Скрипт использует уравнения ренормализационной группы и геометрию $E_8$ для вычисления параметров на энергиях Будущего кольцевого коллайдера ЦЕРН ($\sqrt{s} = 100$ ТэВ). Дает жесткие, проверяемые значения для сильного взаимодействия ($\alpha_s = 0.081829$) и CP-нарушающей фазы нейтрино ($\delta_{CP} = -155.61^\circ$).
