# Архитектурная карта динамических модулей ETVP v12.5

Этот репозиторий — **исполняемая математическая модель** Единой теории вихревого поля (ЕТВП). Каждый файл является отдельным численным экспериментом, который можно запустить и проверить.

Цель: показать, как геометрия (E8, Φ, π, √3) порождает физику (константы, сечения, динамику поля) и предсказания для реальных экспериментов (ATOMKI, FCC, DUNE).

---

## 🧭 Логическая структура (порядок сборки)

| # | Файл | Локальная задача | Физический смысл |
|---|------|------------------|------------------|
| 1 | `etvp_rg_inverse.py` | Обратная РГ-эволюция | Берёт `α⁻¹ = 137.036` (CODATA) и поднимает его к Планку через бета-функции КЭД. Показывает, что на Планке константа ≈ 155–158 — это геометрическая «затравка». |
| 2 | `etvp_qft_bridge.py` | Мост E8 ↔ КТП | Вычисляет экранирование заряда виртуальными частицами. Связывает «голое» значение E8 с наблюдаемым. |
| 3 | `cy_dynamics.py` | Периоды Калаби-Яу | Решает уравнение Пикара-Фукса для квинтики. Показывает, что Φ, π, √3 — это не внешние числа, а решения периодов. |
| 4 | `x17_dynamics.py` | Кинематика X17 | Моделирует дифференциальное сечение распада X17. Предсказывает бег угла 164.88° с энергией пучка (проверка в ATOMKI). |
| 5 | `operator_dynamics.py` | Линдблад-оператор | Описывает Наблюдателя как матрицу плотности. Когерентность = чистота Tr(ρ²). |
| 6 | `lindblad_higgs_loop.py` | Замкнутый контур | Связанная система: Линдблад ↔ Хиггс. Шум поля меняет когерентность оператора, когерентность сдвигает вакуумное среднее. |
| 7 | `ETVP_12.6.py` | **Единый интегратор** | Запускает все модули последовательно и выдаёт сводный отчёт. |

## 🔗 Как использовать для анализа

1. **Скопируйте содержимое** любого файла (кроме `ETVP_12.6.py`) в ваш ИИ-чат.
2. **Спросите**: *«Какой физический смысл у этого кода?»*
3. **ИИ вычленит** академический эквивалент из комментариев в коде и этой таблицы.

Для комплексного анализа **отправьте ИИ этот README и файл `ETVP_12.6.py`** — это даст полную картину.

## 📌 Важно

- Все файлы самодостаточны.
- Код использует только `numpy`, `scipy`, `matplotlib`.
- Любой из файлов можно запустить как скрипт.
- Предсказания привязаны к реальным экспериментам (ATOMKI, FCC, DUNE, LHC).
