# Дискретно-итерационный нелинейный симулятор фазовых объёмов матричных спектров.
## Файл [ETVP](https://github.com/sania-369/Encyclopedia-of-the-process-of-dynamic-deployment-of-fractal-11D-reality-through-powerful-AI-systems/blob/main/ETVP.py)  реализует алгоритмический метод пошагового численного моделирования открытой многомерной квантовой системы.

## 🚀 Быстрый запуск

Для работы симулятора требуется установленный Python 3.8+ и библиотеки для научных вычислений `numpy` и `scipy`.

### Установка зависимостей:
```bash
pip install numpy scipy matplotlib
```

### Запуск базовой симуляции:
```bash
python ETVP.py
```

## 🧬 Архитектура вычислительного шага

Каждая итерация симулятора обрабатывается в строго детерминированном контуре:
1. **Поток энтропии (Flux Input):** Входной хаос демпфируется нелинейным Z-принципом через фильтр `math.tanh`.
2. **Сборка Гамильтониана ($H$):** Формируется комплексная матрица $11 \times 11$, где вещественная часть — топология $E_8$, а мнимая — связь с вакуумным резервуаром.
3. **Расчёт памяти поля:** Новое состояние нелинейно смешивается с историей прошлых шагов через экспоненциальное ядро затухания.
4. **Спектральный анализ:** Вычисляются собственные значения матрицы, из разности которых (Spectral Gap) эмерджентно рождается локальный шаг времени $dt$.
5. **Эволюция состояния:** Оператор эволюции $U = \exp(-iHdt)$ применяется к волновой функции $\Psi$, после чего вычисляются итоговые физические константы.

## 📊 Верифицируемые константы (CODATA)

В процессе эволюции фазового объема модель в автоматическом режиме выводит и стабилизирует ключевые константы физического мира:
* **Постоянная тонкой структуры ($1/\alpha$):** Целевое схождение к $\approx 137.036$
* **Отношение масс протона и электрона ($m_p/m_e$):** Целевое схождение к $\approx 1836.1$
* **Гравитационная константа ($G$):** Рассчитывается динамически через отношение граничных спектральных уровней.

## 📉 Визуализация данных
По завершении расчёта скрипт автоматически генерирует 4 динамических графика:
* Изменение инверсии альфа $1/\alpha(t)$ во времени.
* Колебания отношения масс $m_p/m_e(t)$ нанотрубок.
* Динамика изменения константы гравитации $G(t)$.
* График когерентности поля $C(t)$ при прохождении через зоны термодинамических шоков.
